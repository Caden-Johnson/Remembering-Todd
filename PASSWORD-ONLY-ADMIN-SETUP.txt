PASSWORD-ONLY ADMIN SETUP

The page asks for ONE thing: a password.

Behind the scenes it signs into a dedicated Supabase account:
family-admin@rememberingtodd.local

The email is only an internal username. You never need to type it on the website.

FILES TO UPLOAD TO THE ROOT OF YOUR EXISTING GITHUB REPO
- admin.html
- admin.css
- admin.js
- admin-config.js
- admin-setup.sql

Do not replace config.js.

SUPABASE SETUP
1. Open Supabase -> Authentication -> Users.
2. Click Add user / Create new user.
3. Use this email exactly:
   family-admin@rememberingtodd.local
4. Choose the family password you want.
5. Create the user.
6. Copy that user's UUID / User ID.

7. Go to SQL Editor.
8. Paste and run all of admin-setup.sql.
9. Then run this separately, replacing the value with the UUID you copied:

insert into public.memorial_admins (user_id)
values ('PASTE-USER-UUID-HERE')
on conflict (user_id) do nothing;

10. Visit your GitHub Pages URL with:
    /admin.html

11. Enter only the family password.

SECURITY
- The password is NOT stored in GitHub.
- The admin page has SELECT/read permissions only.
- There are no update or delete permissions/policies for the dashboard.
- Photos remain private and are displayed using temporary signed links.
